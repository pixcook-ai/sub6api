# Tibo 质量探测与自动处置

## 管理入口

系统设置 → 网关服务 → **Tibo 质量探测与自动处置**。面板独立保存，不随其他网关设置一起提交。

首次安装默认关闭后台探测和自动迁组。开启探测后会向各合格账号发送真实 Responses 探测请求，消耗上游用量。建议先关闭自动动作观察记录，再按需要启用。

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 启用后台 Tibo 探测 | 关闭 | 启动账号定向探测及已选择的自动动作 |
| 异常时停止账号调度 | 开启，但受探测总开关控制 | 新鲜明确 degraded 样本写入独立质量隔离标记 |
| 健康后自动解除质量隔离 | 关闭 | 新鲜明确 healthy 样本只清除质量隔离 |
| 按探测结果自动迁移分组 | 关闭 | 按管理员所选的两个分组 ID 迁移 |
| 健康/降智目标分组 | 未选择 | 只有启用自动迁组时才必须选择 |

分组名称没有特殊意义。管理员可选择任意两个不同且启用的 OpenAI 分组，不自动创建分组。自动迁组只处理已经属于这两个组之一的 OpenAI OAuth 账号，保留无关分组、优先级及关联创建时间。分组改名不会破坏配置；组失效时停止该次迁组。

## 探测与判定

迁移保留源方案的固定 Tibo 问题、模型和 reasoning effort；这是启发式信号，不能证明模型内部是否降级。它不等同于延迟、吞吐、配额或 HTTP 可用性监控。

- 探测使用被测账号自身的凭据、代理与原有身份/传输链；支持符合条件的 OAuth、setup-token 和 API key。BPS、gwpool、shadow 及 Agent Identity 等不满足现有探测条件的账号不参与。
- 成功完成的明确答案/拒绝/响应模型匹配用于分类。网络错误、限流、失败或不完整流是 unknown，不因这些错误触发迁组或隔离。
- 已确认的路由健康状态按投票和时效更新；自动迁组及隔离沿用源方案，依据每次新鲜明确主动样本，**不等待投票窗口确认**。因此自动动作和界面 confirmed 状态可能短暂不同。
- 账号界面显示最近 24 次明确样本、最近与下次探测时间、当前判定和质量隔离。管理用量页可按降级路线筛选；普通用户使用记录不新增该内部字段。
- `gateway.openai_tibo_route` 配置调节探测间隔、确认间隔、退避/时效、每小时预算、并发及健康优先排序。常规间隔默认 10 分钟，投票窗口默认 3，确认间隔 20 秒，单账号每小时预算 20 次、进程并发 4。

## 隔离、恢复与关闭

质量隔离通过 `openai_tibo_quality_isolated` 独立运行态标记停止业务调度，**不修改管理员的 Schedulable 开关**。启用质量隔离不要求开启自动迁组或选择任何分组。

隔离检查覆盖普通选号、sticky、previous response 续接、HTTP 及 WS 发送入口。已隔离 previous-response owner 保留绑定并停止继续换号。后台恢复探针可继续访问质量隔离账号；内部豁免绑定账号且不能通过公开 header、body 或相同问题伪造。数据库复核与实际发送之间仍有正常并发窗口，不承诺跨网络原子撤回。

账号编辑中的“解除质量隔离”只清质量标记。管理员手动暂停的账号继续暂停；清除前已发出的旧探测不能重新隔离账号。自动恢复也遵守此限制。

关闭探测总开关后停止新探测和自动动作，保留历史与已有质量隔离；不会自动批量恢复账号。停用自动迁组不迁回已有组。保存设置不会回放旧样本。

## 接口与持久化

- `GET/PUT /api/v1/admin/tibo/settings`：`enabled`、`auto_group_enabled`、`healthy_group_id`、`degraded_group_id`、`pause_on_degraded`、`auto_resume_on_healthy`。
- `POST /api/v1/admin/accounts/:id/tibo/clear-isolation`：解除独立质量隔离，保留管理员调度状态。
- settings key 为 `openai_tibo_settings`，读取有短缓存；事务自动动作重新读取持久化配置。
- 观察、质量动作、组关联与 scheduler outbox 同事务；按样本时间防止乱序回写，绑定探测凭据/代理身份，管理表单不能伪造运行态字段。调度缓存版本包含 Tibo 状态及清除围栏。
- 新迁移 260 增加 nullable `usage_logs.route_degraded`，261 增加并发部分索引；既有迁移保持不变。`NULL` 为不适用，`false` 为健康/unknown 路线，`true` 为降级路线。该字段不影响计费。
